# 🫁 LCTfound: A Foundational Model for Lung CT Imaging and Analysis

**LCTfound** is a foundational model for lung computed tomography (CT), designed to empower a broad spectrum of clinical tasks with a single, robust, self-supervised learning framework.

This repository provides code for:
- 🔧 **Pretraining** based on diffusion models (completed and available)
- 📊 **Downstream tasks** such as diagnosis, segmentation, and reconstruction (in progress and coming soon)

---

## 📘 About LCTfound

> *“The concomitant development and evolution of lung computed tomography (CT) and artificial intelligence (AI) has allowed non-invasive lung imaging to be a key part of the clinical care of patients with major diseases, such as lung cancer.”*

Despite advances in AI, the lack of large-scale labeled datasets has hindered real-world clinical deployment of AI in lung CT. **LCTfound** addresses this by learning from over **105,000 lung CT scans** (totaling more than **28 million images**) across multiple centers using self-supervised **diffusion-based pretraining**.

## 🧪 Python Environment Setup with `uv`

This project is built with **Python 3.10+** and leverages [`uv`](https://github.com/astral-sh/uv) — a fast, modern Python package manager — for efficient and reproducible environment management.

---

### 📥 1. Install `uv`

Install `uv` by running the following script:

```bash
curl -Ls https://astral.sh/uv/install.sh | bash
```

After installation, make sure the `uv` command is available in your terminal. You may need to restart your shell or add `uv` to your `PATH`.

---

### 🧱 2. Create and Activate a Virtual Environment

Create a virtual environment in the current directory:

```bash
uv venv
```

Then activate it:

- **macOS / Linux**:
  ```bash
  source .venv/bin/activate
  ```

- **Windows**:
  ```bash
  .venv\Scripts\activate
  ```

---

### 📦 3. Install Required Dependencies

Use `uv pip` to install the project's core dependencies.

#### 🔥 Install PyTorch (with CUDA 12.4)

```bash
uv pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
```

#### 📚 Install Key Packages

```bash
uv pip install \
  monai SimpleITK nibabel scikit-image opencv-python \
  matplotlib pandas numpy scipy scikit-learn \
  transformers diffusers accelerate tokenizers \
  tensorboardX tqdm requests PyYAML
```
